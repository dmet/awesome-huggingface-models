# RealEyesVR Test Lab

An early, source-linked construction schedule extraction experiment.

## Current mode

The first release accepts a single PDF or image and uses a clearly labeled
simulated extraction so the interface, authentication boundary, schema,
validation, and result presentation can be tested before consuming ZeroGPU
quota.

Real Qwen inference will be enabled only after a checkpoint, prompt, image
resolution, and benchmark case have been selected and documented.

## Privacy

Do not upload confidential, client, employer, personal, or otherwise restricted
documents. Use public, synthetic, personally owned, or explicitly authorized
test data only.

Uploads and results are not intentionally persisted by this application.
